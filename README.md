# 藤井ただし（藤井 規示）公式サイト

亀岡市の藤井ただし（藤井 規示）の公式サイト。GitHub Pages で公開する静的サイトです。

## 構成

- `index.html` … トップページ
- `greeting.html` … ごあいさつ
- `career.html` … 経歴
- `profile.html` … パーソナルデータ
- `support.html` … 後援会に入会する
- `assets/css/style.css` … スタイル
- `assets/js/nav.js` … モバイルメニュー
- `assets/img/` … 画像

## 公開（GitHub Pages）

Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定します。
公開URL: https://asaty94.github.io/website-fujii-tadashi/
